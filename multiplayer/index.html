Group setup

Multiplayer is designed for people gathered around one phone, tablet, or computer. It is not a remote lobby or networked room.

How rotation works

Every player receives the same reference

For scene one, Player 1 hears and imitates the selected performance, reviews the take, and reveals the panel. The handoff then names Player 2. The scene stays the same until every player completes it, which keeps the within-room comparison meaningful. Only then does the game draw the next scene.

Scores combine four completed scenes

Each performance receives timing, energy, and pitch feedback plus five judge votes. After all players finish all four scenes, the local board summarizes results by name. The game does not create public profiles, permanent rankings, or a network leaderboard.

Arrange the room before starting

Place the device where each player can use roughly the same microphone distance. Headphones reduce reference-audio leakage, but sharing one pair can slow the handoff; a moderate speaker volume in a quiet room can work if players wait until the reference ends. Silence notifications and close apps that might claim the microphone.

Use player names that are easy to recognize

Short names keep handoff prompts readable. Enter the order physically nearest to the device path, especially with four players. The named button tells the group exactly who performs next, so avoid swapping order after the show begins.

Keep judging playful and accessible

The computer panel measures performance similarity, not acting ability or voice quality. Players can use their natural range and skip uncomfortable vocal effects. Allow a retry for interruptions, laughter over the recording, or a dropped device; keep the first clean take when the goal is a friendly challenge.

What this multiplayer mode does not include

There is no room code, remote audio, account invitation, cross-device synchronization, text chat, or online matchmaking. For people in different locations, use a separate call and take turns screen-sharing Solo mode, understanding that the scores will not merge into one board.

Host checklist

Before pressing Group

  • Gather 2–4 players
  • Pick a passing order
  • Use one stable microphone
  • Lower room noise
  • Explain the four-light start
  • Agree when retries are allowed

A typical four-scene session gets longer with each added player; leave time for replay and handoff.
