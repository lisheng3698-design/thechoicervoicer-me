What is verified

What is The Choicer Voicer?

The Choicer Voicer is a browser voice-imitation party game: hear a short character performance, copy its timing and vocal movement, replay your take, and face five computer judges.

This edition supports one to four local players and runs with original TypeScript, Web Audio analysis, interface design, scoring logic, and rights-cleared dialogue performances. It does not use commercial movie audio.

How to play

Listen. Perform. Face the panel.

Every recording stays in this tab. Use headphones so the reference clip does not leak back into the microphone.

1

Choose the lineup

Select one to four local players and enter names. Everyone shares the same device and microphone.

2

Hear the character

Play the original performance, read the source and character card, then imitate the dialogue line in one timed take.

3

Collect judge votes

Five computer judges convert the local similarity analysis into 0–5 approvals. An exceptional match can reach 6/5.

FAQ

What to know before you play.

Learn how the browser edition handles voice assets, microphone recordings, scoring, and device support.

Who built this browser game?

This browser edition uses original TypeScript, Web Audio scoring, interface design, and rights-cleared voice assets created for thechoicervoicer.me.

What audio is included?

The library contains original film-style performances and public-domain literary dialogue rendered as purpose-made voice assets. It does not bundle commercial movie audio.

Where does my recording go?

It remains a temporary browser object in this tab. There is no upload endpoint, account, or server-side voice storage.

How does scoring work?

The browser scoring model compares timing, energy contour, and pitch movement, then maps the result to five judge votes.

Does it work on phones?

It is designed for current mobile browsers with microphone and MediaRecorder support. HTTPS is required after deployment.

Can I load community packs?

Not in this build. Pack files contain third-party media and should only be used when their author grants permission.
