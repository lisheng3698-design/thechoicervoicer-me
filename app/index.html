Browser app · No account · No APK

Use The Choicer Voicer app in your browser.

This independent web edition opens instantly on desktop or mobile. It provides the playable voice-imitation loop without claiming to be a native app-store release.

App facts

What this browser edition includes.

The page separates the web app you can use here from unrelated native listings, downloads, and third-party packages.

Runs in a browser

Use a current Chrome, Edge, Firefox, or Safari browser with JavaScript, audio playback, and microphone permission.

No installation file

There is no APK, Windows installer, Steam build, or account download supplied by this site. The current product is the web edition.

Local microphone processing

Your take becomes a temporary browser object for replay and scoring. It is not uploaded to a server.

Before opening the app

Choose the right way to launch it

Open the game from the secure thechoicervoicer.me address, press the play button, and allow microphone access only when the sound-check step asks. If another page offers a file under a similar name, that file is outside this browser edition and is not required here.

Features available now

The web app supports one to four players sharing a device, a randomized four-scene show, replay before scoring, local timing/energy/pitch comparison, five computer-judge votes, and a final leaderboard. The bundled scene reel contains 16 bilingual, rights-documented performances.

What the browser app does not promise

It does not provide online matchmaking, cloud saves, user accounts, community uploads, native push notifications, or an offline installer. Closing the tab ends the temporary microphone session and clears the in-page recording object.

App questions

Can I add it to a home screen?

Some browsers can save a website shortcut, but behavior varies by browser and operating system. A shortcut still opens the browser edition; it does not turn the site into a native store app.

Why does an in-app browser fail?

Social-media and messaging-app browsers may restrict audio playback or microphone APIs. Open the same URL in Safari, Chrome, Edge, or Firefox.

Where should I start?

Read the step-by-step game instructions, check the mobile setup guide, or open the voice imitation game.
