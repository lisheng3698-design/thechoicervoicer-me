Quick help

For microphone issues, confirm browser permission, use an HTTPS page, disable silent mode, try headphones, and reload the current tab before starting a new soundcheck.

Browser challenge feedback

A public inbox for this independent project is not yet configured. Until domain mail is active, the game page includes self-service microphone troubleshooting and exposes no form that could falsely promise delivery.

Current status: no contact form or inbox is presented as active. A working domain email will be published here before ads, submissions, accounts, or other user-data features are enabled.

Rights concerns

If you own material that you believe appears here, keep the exact URL and a description of the material. A rights-contact route will be added with the domain inbox; the current release intentionally contains no copied commercial or community pack audio.
