Voice Over Script Formatting

Prepare a readable voice-over script with stable line IDs, separate spoken copy and directions, and a visible revision. The six checks help a performer and director discuss the same line without accidentally reading production notes aloud.

Start the six-step routineRead the original example

Controlled practice

Work through the routine one step at a time.

Change one variable, listen back, then mark the step. Progress stays on this device and carries across the language switch. The checklist stores completion flags, never recordings.

1

Create stable line IDs

Assign one ID to each spoken unit. Keep that ID during revisions so a pickup request can still refer to the intended line.

2

Separate direction from speech

Put production directions in a visibly distinct label or column. Read the page once and identify exactly what should and should not be spoken.

3

Mark pronunciation notes

Place an approved pronunciation beside its first occurrence and in a separate note. Never silently change a proper name to make it easier.

4

Expose the revision

Add the project, revision, and date to the header. Give changed lines a clear marker without overwriting the previous file.

5

Check the actual reading view

Open the file on the screen or print layout used during recording. Check that small text, page breaks, and hidden columns do not split an important unit.

6

Dry-run a pickup

Ask someone to request line 02 in revision 3. Confirm you find the same spoken text and the current direction before treating the format as usable.

0 of 6 steps completed. Self-review, not an audio score.

Original practice card

Use one fixed example for a fair comparison.

Lantern / revision 3 / rehearsal. ID 01 | Direction: warmly, to one visitor | Spoken: Your room is ready. ID 02 | Direction: practical, no urgency | Spoken: Please collect your key at the blue desk.

How should the first pass work?

Read the original example and limits, then work through the six steps using your own notes and any equipment required by the task. Keep a baseline or current version and check the stated result before marking a step complete. The checklist records your progress locally; it does not inspect files, judge audio, or perform the task for you.

Observable result

Check the result against the criteria.

A reader should locate an ID without searching by sentence fragments and should never confuse a direction with spoken words. Confirm the same revision on both ends of a handoff.

A checked box records that you completed a step. It does not certify voice quality, skill, or professional readiness.

Screenplay V.O. or a recording sheet?

For screenplay narration, place (V.O.) with the character name and keep the spoken line in its dialogue block. A studio recording sheet instead uses stable line IDs and separate directions. Preserve the original screenplay version when preparing the recording sheet. Here is an original example of the two representations.

Screenplay: MARA (V.O.)
The lantern waits at the east gate.

Recording sheet: L01 | MARA | narration | The lantern waits at the east gate.

Limits and failure cases

Repair a failed comparison before continuing.

This is a manual formatting guide, not a document converter or script editor. Follow the receiving studio template when supplied; IDs are organizational aids, not automatic synchronization.

Too many simultaneous changes

Changing words, level, position, and pace together makes the comparison inconclusive. Return to the example baseline and retain only the variable specified by the current step.

Impressions instead of evidence

A more attractive sound does not establish that the task worked. Apply the page-specific playback checks, and ask a listener unfamiliar with the example to recount the information before keeping a take.

Effort used to force completion

The completion record is not an endurance contest. Stop at discomfort, shorten the session, and return to comfortable speech; pain or excessive vocal effort is never a condition for checking a box.
