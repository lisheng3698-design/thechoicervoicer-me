Privacy policy

The current browser challenge is designed so your recorded voice remains on your device.

Microphone access

The game asks for microphone permission only after you press the soundcheck button. The browser provides a live media stream to in-page Web Audio and MediaRecorder APIs. Signal measurements are computed locally.

Recordings

A take becomes a temporary browser object URL so you can replay it. The site has no audio-upload endpoint and does not transmit or save the recording to a server. Ending the mic session or closing the tab stops the stream and discards the temporary playback object.

Accounts, analytics, and advertising

This release has no user accounts, forms that collect personal details, advertising scripts, or third-party analytics tags. The code exposes privacy-safe event names for future measurement, but no measurement provider is connected at launch.

Hosting logs

The hosting provider may process ordinary request information such as IP address, user agent, requested URL, and timestamps for security and delivery. This is separate from microphone audio, which is not part of page requests.

Children

The site does not knowingly collect children’s personal information. A parent or guardian should control browser permissions for younger players.

Changes

If uploads, accounts, analytics, ads, or other data collection are added, this policy must be updated before those features go live.
