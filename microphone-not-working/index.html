Three-minute check

Fix permission, input, then interference.

Work in this order. Changing several audio settings at once makes the actual cause harder to identify.

1

Allow this site

Open the controls beside the address bar, set Microphone to Allow for thechoicervoicer.me, then reload the page.

2

Select one input

Choose the built-in microphone or the headset you intend to use. Reconnect Bluetooth before opening sound check.

3

Free the microphone

Close calls, recorders, camera apps, and other browser tabs that may hold the input. Speak normally and watch the meter.

Symptom guide

If the browser never asks for permission

The request appears only after you press the microphone-check button. If nothing appears, look for a blocked-microphone icon in the address bar. Change the site setting to Allow, reload, and press the button again. A private window or a full Safari, Chrome, Edge, or Firefox window can also rule out an embedded browser that does not expose recording features correctly.

If permission is allowed but the meter stays still

Check the operating system input first. On a laptop with a connected display or headset, the selected device may have changed. Speak while viewing the system input level; if that meter is also still, reconnect the device or switch to the built-in microphone. If the system meter moves but the game does not, close other tabs, reload this page, and run sound check again.

If the meter moves but recording is quiet or clipped

Keep the microphone about a hand’s width away. Move closer when the meter barely reacts; move back when it stays at maximum. Remove a case that covers the phone microphone, and avoid rubbing the device. A consistent distance gives timing, energy, and pitch analysis a cleaner signal.

If the recording contains the reference audio

Use headphones and lower speaker volume. The game plays a reference before recording, but room echo can remain audible and distort the comparison. Wait until playback finishes, keep the device still, and record only when the button becomes available.

If the microphone works but scores seem too low

This is usually a performance or echo issue, not a permission failure. Match the full duration and longest pauses first, then copy loud–soft movement and pitch direction. Review the gameplay and scoring guide before changing more system settings.
