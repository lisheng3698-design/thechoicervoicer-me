Using the pack

How the game turns scenes into rounds

At the start of a show, the browser loads the local JSON manifest, shuffles the cue list, and selects four scenes. Each round shows the source, character, scene context, rights status, and voice direction before the player records a take.

Why the pack does not include commercial clips

Commercial films, games, actors, and community uploads can carry copyright, voice, and distribution restrictions. This edition uses original or public-domain source material and keeps a source URL plus rights note for every classic entry.

Can I add a custom voice pack?

Not through the current public interface. The game has an internal pack structure, but this site does not offer uploads or promise compatibility with third-party packs. Any future contribution flow would need permission records, file validation, moderation, and a privacy update before launch.

Voice pack questions

Are English and Chinese rounds identical?

They share the same scene identity and scoring concept, but each language has its own dialogue wording, duration, performance, and analysis reference.

Can I choose one specific scene?

The current show draws four random scenes. The full table above helps you understand the available reel before playing.
