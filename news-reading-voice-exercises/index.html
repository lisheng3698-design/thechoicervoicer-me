News Reading Voice Exercises

Practice an intelligible bulletin while preserving attribution, numbers, and uncertainty. The exercises teach an approved script as information, with clearly separated headlines and corrections. They do not turn fictional practice copy into reporting or authorize changes to facts.

Start the six-drill routineRead the original example

Controlled practice

Work through the routine one drill at a time.

Change one variable, listen back, then mark the drill. Progress stays on this device and carries across the language switch. The checklist stores completion flags, never recordings.

1

Source labels

Underline who said each claim. Record the attribution with enough emphasis that the audience does not mistake a statement for an independently verified fact.

2

Headline and detail

Read a headline, leave a small separation, then deliver supporting detail. Ask a listener whether they hear one item or two unrelated stories.

3

Number grouping

Mark units beside each number. Read amount and unit together, then check a transcript against the approved script instead of trusting memory.

4

Uncertainty preservation

Circle “estimated,” “reported,” and other qualifications. Record them at the same clear level as the claim rather than rushing through them.

5

Correction practice

Write an explicit correction naming the earlier error and the correct value. Avoid vague wording that leaves listeners unsure which information changed.

6

Cold bulletin check

Give an unseen approved practice bulletin to a partner. Compare their written facts with the source after one hearing and repair only misunderstood phrases.

Original practice card

Use one fixed example for a fair comparison.

Fictional practice bulletin: “The organizers say the exhibition will open at ten on Saturday. Attendance is estimated at three hundred visitors. Correction: the earlier practice script gave an opening time of nine; the approved time is ten.” Keep “say,” “estimated,” and the correction audible. Do not post this as a real event announcement.

How should the first pass work?

Read the example and limits before starting, keep a baseline, and work through the six drills above. Make two takes with a recording device you control and note the specific change privately. On playback, check that information remains intact before judging expressive choices. Stop if uncomfortable; no audio upload is needed.

Observable result

Judge the result on playback.

The listener recalls the event, time, source, qualified attendance estimate, and corrected value. A polished take fails if it drops attribution, changes a unit, or makes an estimate sound certain. Read back numbers separately after the expressive pass; preserve the script version so the correction can be traced.

Limits and failure cases

Repair a failed comparison before continuing.

Use original fictional bulletins or scripts you are authorized to record. This page provides delivery drills, not journalism verification. Editorial approval controls factual changes; dramatic emphasis must never create a claim absent from the approved script.

Too many simultaneous changes

Changing words, level, position, and pace together makes the comparison inconclusive. Return to the example baseline and retain only the variable specified by the current drill.

Impressions instead of evidence

A more attractive sound does not establish that the task worked. Apply the page-specific playback checks, and ask a listener unfamiliar with the example to recount the information before keeping a take.

Effort used to force completion

The completion record is not an endurance contest. Stop at discomfort, shorten the session, and return to comfortable speech; pain or excessive vocal effort is never a condition for checking a box.
