设备设置

根据手机选择正确方式。

菜单名称会随系统和浏览器版本变化，但游戏始终需要音频播放、录音 API 和本站麦克风权限。

iPhone 与 iPad

使用最新版 Safari 或其他完整浏览器，检查静音模式和媒体音量，再在提示时允许麦克风。

Android

使用最新版 Chrome、Edge、Firefox 或系统完整浏览器，并关闭其他占用麦克风的通话或录音应用。

避开内嵌浏览器

社交或聊天应用内打开的页面可能限制播放和录音，请先选择“在浏览器中打开”。

手机检查清单

授权前先准备声音

把媒体音量调到舒适水平，并尽量佩戴耳机。扬声器播放可能被麦克风再次录入，让评分比较到参考音频而不是你的表演。

允许本站访问麦克风

权限提示只会在开始声音检测后出现。允许本站访问，正常说话，并等待输入电平变化。麦克风流只用于当前标签页中的本地分析。

恢复曾经拒绝的权限

打开地址栏旁的网站控制，把麦克风从阻止改为允许，然后刷新。如果找不到该设置，请在系统隐私设置中检查当前浏览器的麦克风权限。

录音时保持手机稳定

把设备放在稳定表面，或与嘴保持固定距离。遮住麦克风、录音中旋转设备、切换应用或接听电话都可能中断本次录音。

手机常见问题

需要安装 App 吗？

不需要。当前版本直接在浏览器运行。主屏幕快捷方式仍然只会打开网站。

多人可以共用一部手机吗？

可以。选择 2–4 名本地玩家，每回合传递同一台设备；当前没有远程房间。

为什么听不到参考音频？

关闭静音模式、提高媒体音量，点击页面一次满足浏览器播放规则，并改用完整浏览器重试。
